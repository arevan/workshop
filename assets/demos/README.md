# Записи демок для слайда «Немного демок»

Скринкасты, которые крутятся в рамках телефонов на слайде 6.
Файлы называются по порядку: `case-1.mp4`, `case-2.mp4`, … Сколько файлов
перечислено в слайде — столько телефонов в ряду, и тем они крупнее.
Если файла нет, экран остаётся пустым — слайд не ломается.

## Что лежит сейчас

| Файл | Что на записи | Длина |
|---|---|---|
| `case-1.mp4` | Выбор процента кэшбэка на благотворительность | 10 сек |
| `case-2.mp4` | Плейграунд шейдеров: Ripple, Sphere, Blob, Confetti | 95 сек |
| `case-3.mp4` | Смена темы и иконки приложения | 13 сек |

## Как добавить ещё

Записать вертикально — как снимает телефон или симулятор. Хорошая длина
10–20 секунд: один проход сценария. Ролики зациклены и без звука,
поэтому конец лучше сводить к началу.

**Симулятор iOS:** File → Record Screen. **iPhone:** запись экрана
из Пункта управления.

Дальше ужать — исходники с телефона весят десятки мегабайт:

```bash
ffmpeg -i исходник.mov -vf "scale=540:-2,fps=30" -c:v libx264 -pix_fmt yuv420p -crf 30 -movflags +faststart -an case-4.mp4
```

`-an` убирает звук, `fps=30` вдвое режет вес записи с айфона (он пишет 60),
`crf 30` даёт сильное сжатие без заметной потери на таком размере,
`+faststart` — чтобы видео начинало играть, не дожидаясь полной загрузки.
Норма — до 2 МБ на ролик; для длинных вроде `case-2` терпимо до 3–4 МБ.

Положить исходники можно в `assets/screenshots/` — эта папка в `.gitignore`,
в репозиторий уезжают только сжатые mp4 отсюда.
