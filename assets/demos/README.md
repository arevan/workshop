# Записи демок для слайда «Собранные кейсы»

Сюда кладутся скринкасты, которые показываются в рамках телефонов
на слайде 6. Пока файла нет, экран остаётся пустым — слайд не ломается.

## Что нужно

Пять вертикальных записей экрана: `case-1.mp4` … `case-5.mp4`.

- Вертикальные, как снимает телефон или симулятор
- 10–20 секунд: один проход основного сценария
- Без звука — на слайде он всё равно выключен
- Зациклятся сами, поэтому конец лучше сводить к началу

## Как записать

**Симулятор iOS:** `Cmd + R` в меню File → Record Screen, либо кнопка записи
на панели. Сохранится .mov, его можно положить как есть.

**iPhone:** запись экрана из Пункта управления.

## Как ужать

Файлы должны быть лёгкими — их пять на одном слайде:

```
ffmpeg -i исходник.mov -vf "scale=540:-2" -c:v libx264 -crf 30 -an case-1.mp4
```

`-an` убирает звук, `crf 30` даёт заметное сжатие без видимой потери
на таком размере. Норма — до 2 МБ на ролик.
