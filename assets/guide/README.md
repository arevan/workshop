# Скриншоты для гайда

Сюда кладутся картинки, которые подставляются в разделы гайда.
Имя файла = то, на что ссылается markdown в `content/guide/*.md`.
Если файла нет, блок с картинкой просто не показывается — гайд не ломается.

## Раздел «Окружение: iPhone»

| Файл | Что на скриншоте |
|---|---|
| `xcode-01-welcome.png` | Стартовый экран Xcode с кнопкой Create New Project |
| `xcode-02-template.png` | Выбор шаблона: вкладка iOS, App |
| `xcode-03-options.png` | Параметры проекта: Product Name, Team, SwiftUI |
| `xcode-04-location.png` | Выбор папки + галочка Create Git repository |
| `xcode-05-signing.png` | Вкладка Signing & Capabilities без ошибок |
| `xcode-06-device.png` | Список устройств в шапке, выбран iPhone |
| `ios-01-untrusted.png` | Алерт «Недоверенный разработчик» |
| `ios-02-search.png` | Поиск «VPN и управление устройством» в настройках |
| `ios-03-management.png` | Раздел «ПО разработчика», статус «Недоверенный» |
| `ios-04-trust.png` | Экран с кнопкой «Доверять приложению» |

| `ios-06-hello.png` | Собранное приложение на телефоне: Hello, world! |

Файлы с `ios-` в имени и словом `phone` рендерятся узкой колонкой
(вертикальный скрин телефона), остальные — на всю ширину.
Оба варианта — со скруглением.

## Как добавить свою картинку в гайд

В нужном месте `content/guide/*.md` поставь строку:

```
![Подпись под картинкой](../assets/guide/имя-файла.png)
```

Подпись показывается серым под изображением — её можно оставить пустой:
`![](../assets/guide/файл.png)`.
