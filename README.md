# Воркшоп по вайбкодингу — слайды и гайд

Сайт вводного воркшопа для продуктовых дизайнеров: презентация, раздатка
и одновременно — твой первый учебный проект для вайбкодинга. Он собран так же,
как ты будешь собирать демки: AI-агентом, маленькими итерациями.

## Как открыть

Скачай архив проекта или склонируй репозиторий:

```bash
git clone https://github.com/arevan/workshop.git
```

Открой терминал в папке проекта и запусти любой вариант:

```bash
npx serve
```

```bash
python3 -m http.server 4173
```

Открой адрес из вывода — например `http://localhost:4173`.

- `/slides/` — презентация: стрелки или клик — листать, `F` — фуллскрин, `N` — заметки спикера, `#7` в адресе — прямая ссылка на слайд
- `/guide/` — раздатка: окружение, промты, git, чек-лист перед хакатоном

Сервер нужен, потому что тексты лежат отдельными файлами в `content/`,
а браузер не даёт странице читать локальные файлы без него. Если открыть
`index.html` двойным кликом — сайт сам покажет эту инструкцию.

## Первое упражнение

Открой папку проекта в своём AI-агенте (Codex, Claude Code — любой) и попроси,
по нарастающей:

1. «Найди, где лежит текст третьего слайда, и замени в нём одну формулировку»
2. «Сделай, чтобы строки на слайдах появлялись медленнее и с большей задержкой друг за другом»
3. «Добавь в гайд новый раздел „Мои заметки“ с парой пунктов»

После каждой правки обнови страницу. Это тот же цикл
«изменил → Run → проверил», что и на воркшопе.

## Как править контент

Тексты отделены от кода — компоненты трогать не нужно:

- слайды: `content/slides/*.md` (один файл — один слайд; поля вверху:
  `title`, `aside` — правый абзац, `notes` — заметки спикера, `layout`,
  `enabled: false` — выключить слайд; `==текст==` — жёлтый акцент)
- порядок слайдов: `content/slides/manifest.json`
- гайд: `content/guide/*.md` (обычный markdown плюс `> текст` — заметка
  на полях и `![Подпись](../assets/guide/файл.png)` — скриншот)
- скриншоты для гайда: `assets/guide/` — какой файл куда встаёт, описано
  в `assets/guide/README.md`
- цвета, шрифты, скорость анимаций: `css/tokens.css`

## Структура

```
index.html           хаб
slides/  guide/      презентация и раздатка
content/             все тексты (markdown)
css/  js/            стиль и движок (читаемые, с комментариями)
SKILL.md             дизайн-система проекта — агент подхватит её сам
```

Шрифт — Manrope (SIL Open Font License), лежит в `assets/fonts/`.
Внешних зависимостей нет: без CDN, без бэкенда, без аналитики.
