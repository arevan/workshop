Путь короче, чем на iOS: никаких подписей, сертификатов, Developer Team и Apple ID. Телефон, кабель, галочка в настройках — и агент делает всё остальное, включая создание проекта и запуск сборки.

Понадобится: компьютер с Android Studio, телефон с кабелем, AI-агент.

## 1. Поставить Android Studio

Скачай с [developer.android.com/studio](https://developer.android.com/studio) и пройди первый запуск, не меняя настроек: мастер сам докачает Android SDK — без него агент не сможет ничего собрать.

Это самый долгий шаг, минут пятнадцать. Сделай заранее, не в день хакатона.

> Сам проект создавать руками не нужно — этим займётся агент. Android Studio ставится ради SDK и как запасной способ нажать Run.

## 2. Включить режим разработчика на телефоне

Он спрятан, включается «пасхалкой»:

1. Настройки → **О телефоне**
2. Найди **Номер сборки** и нажми на него **семь раз подряд**
3. Введи код разблокировки — появится «Вы стали разработчиком»
4. Вернись в Настройки → **Для разработчиков** (иногда внутри «Система» или «Дополнительно»)
5. Включи **Отладка по USB**

> Пункты меню называются по-разному у Samsung, Xiaomi и Pixel, но логика одна: семь тапов по номеру сборки, потом USB-отладка. Не находишь — вбей «номер сборки» в поиск по настройкам.

## 3. Подключить телефон

Подключи кабелем. На телефоне появится запрос **Разрешить отладку по USB** — согласись и поставь галочку «Всегда разрешать с этого компьютера».

Проверить, что компьютер видит телефон, можно одной командой в терминале:

```
adb devices
```

В списке должна появиться строка с идентификатором устройства и словом `device`. Если пусто или написано `unauthorized` — вытащи и вставь кабель, посмотри на экран телефона (там висит запрос) и проверь режим подключения: должна быть «Передача файлов», а не «Только зарядка». Часть кабелей умеет только заряжать — это самая частая причина.

## 4. Попросить агента собрать демку

Открой папку, где будет жить проект, в своём агенте и опиши, что нужно. Проект он создаст сам:

```
Создай Android-проект на Kotlin и Jetpack Compose.
Экран: карточка товара — изображение-заглушка, название, цена, кнопка.
По тапу на кнопку карточка переходит в состояние «Добавлено» с анимацией.
Собери и установи на подключённый телефон.
```

Агент создаст структуру проекта, напишет экран и поставит сборку на телефон командой `./gradlew installDebug`. Приложение появится на телефоне — открой его и проверь руками.

Дальше цикл повторяется, и в IDE переключаться не нужно: попросил изменить → попросил пересобрать → проверил на телефоне. Чтобы не просить о пересборке каждый раз, запиши это правилом — см. [Правила проекта](#agents).

> Если сборка не ставится, попроси агента показать вывод команды целиком — обычно там прямо написано, чего не хватает: не найден SDK, не подключён телефон, занят порт.

## 5. Android Studio как запасной путь

Открывать проект в Android Studio не обязательно, но иногда удобно: посмотреть ошибку в **Logcat**, нажать **Run** руками, если агент застрял. Для этого открой созданную агентом папку через **Open** и дождись Gradle sync.

Промтинг для Compose не отличается от SwiftUI — это такой же декларативный UI. Всё из раздела [Шаблон промта](#prompts) работает без изменений.
