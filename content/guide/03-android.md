Если у тебя Android-телефон — путь короче, чем на iOS. Никаких подписей, сертификатов, Developer Team и Apple ID: телефон, кабель, галочка в настройках.

Понадобится: компьютер с Android Studio, телефон с кабелем, AI-агент.

## 1. Поставить Android Studio

Скачай с [developer.android.com/studio](https://developer.android.com/studio) и пройди первый запуск, не меняя настроек: мастер сам докачает SDK и всё, что нужно. Это самый долгий шаг — минут пятнадцать, лучше сделать заранее.

## 2. Создать проект

**New Project** → шаблон **Empty Activity** (он на Compose) → **Next**. Заполни:

- **Name** — название проекта
- **Package name** — оставь как предложили
- **Language** — Kotlin, **Build configuration language** — как по умолчанию

Нажми **Finish** и дождись, пока внизу закончится Gradle sync — первая синхронизация тоже небыстрая.

## 3. Включить режим разработчика на телефоне

Он спрятан, включается «пасхалкой»:

1. Настройки → **О телефоне**
2. Найди **Номер сборки** и нажми на него **семь раз подряд**
3. Введи код разблокировки — появится сообщение «Вы стали разработчиком»
4. Вернись в Настройки → **Для разработчиков** (иногда внутри «Система» или «Дополнительно»)
5. Включи **Отладка по USB**

> Пункты меню называются по-разному у Samsung, Xiaomi и Pixel, но логика одна: семь тапов по номеру сборки, потом USB-отладка. Если не находишь — вбей «номер сборки» в поиск по настройкам.

## 4. Подключить и запустить

Подключи телефон кабелем. На телефоне появится запрос **Разрешить отладку по USB** — согласись и поставь галочку «Всегда разрешать с этого компьютера».

В шапке Android Studio выбери свой телефон в списке устройств и нажми **Run** (зелёный треугольник). Сборка поставится на телефон и откроется сама.

Если телефон не появился в списке — вытащи и вставь кабель, проверь на телефоне режим подключения (должен быть «Передача файлов», не «Только зарядка») и попробуй другой кабель: часть кабелей умеет только заряжать.

## 5. Подключить AI-агента

Открой папку проекта в своём агенте и попроси собрать первый экран. Промтинг для Compose не отличается от SwiftUI — это такой же декларативный UI:

```
Сделай экран с карточкой товара: изображение-заглушка, название, цена и кнопка. По тапу на кнопку карточка переходит в состояние «Добавлено» с анимацией.
```

Дальше — обычный цикл: попросил → Run → проверил руками.
