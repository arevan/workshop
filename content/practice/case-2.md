Экран дебетового счёта и флоу выпуска допкарты — по [макету в Figma](https://www.figma.com/design/2UQNBYDCGL5UrNXp1JbTJX/Воркшопы?node-id=44-4732). Три промта, которые доведут их до рабочего состояния через Figma MCP.

> Формат другой, чем у песочницы: здесь работаем с подключённой Figma. Промты и скрины ниже показывают, что должно получиться на каждом шаге. Подключишь Figma — сможешь повторить кейс этими же промтами; как подключить, написано [в гайде](../guide/index.html#figma).

## Экран счёта

Первый шаг с экраном счёта целиком: карусель карт, баланс, кэшбэк, операции, детали. Он самый долгий из трёх — дальше промты короче.

![](../assets/practice/case-2-step-1-tall.png)

```
Контекст: демка воркшопа, приложение с меню «Практика». Собираем кейс
«Выпуск новой карты»: экран дебетового счёта и флоу выпуска допкарты
по макетам из Figma.

Задача: собери экран счёта по макету
https://www.figma.com/design/2UQNBYDCGL5UrNXp1JbTJX/Воркшопы?node-id=23-35675
Цвета, шрифты, отступы и скругления бери из макета. Картинки и иконки уже
лежат в Assets.xcassets, выгружать из макета ничего не нужно: карта счёта —
AccountCardBlack, логотип — LogoMir, иконки — IcRoller, IcRollerColored,
IcFlower, IcForkKnife, IcGasStation, IcRestaurants, IcShoppingBag, IcTaxi,
IcPencil, IcPlus, IcQrScan, IcArrowRight, IcChevronRight, IcCheckSmall.

Поведение: тап по пункту «Выпуск новой карты» в меню → открывается этот
экран. Лента карт в шапке свайпается со снэпом: за чёрной картой справа
выглядывает пунктирная карта с плюсом — пока без действия. Контент
скроллится, таб-бар внизу статичен.

Ограничения: статус-бар, навигация и таббар — нативные компоненты iOS
(NavigationStack, TabView), не рисуй их по макету картинками. Не добавляй
обводок и колец, которых нет в макете. Меню и кейс с эмодзи не трогать.

Готово, когда: экран совпадает с макетом по цветам, шрифтам и порядку
блоков; лента карт свайпается; после карточки «Детали» отступ 32.
```

## Флоу выбора: получатель и тип карты

Тап по пунктирной карте с плюсом открывает флоу выпуска: два экрана списком, один за другим внутри общего шита. Оба короткие — карточка, галочка, «Продолжить».

![](../assets/practice/case-2-step-2.png)

```
Контекст: продолжаем кейс «Выпуск новой карты».

Задача: начинаем флоу выпуска. Тап по контурной карте с плюсом открывает
его модально, внутри два шага пушем:
1. «Для кого вы хотите выпустить допкарту?» — макет
https://www.figma.com/design/2UQNBYDCGL5UrNXp1JbTJX/Воркшопы?node-id=23-39548
2. «Выберите тип карты» — макет
https://www.figma.com/design/2UQNBYDCGL5UrNXp1JbTJX/Воркшопы?node-id=23-39537

Поведение: выбранный вариант отмечается галочкой, «Продолжить» ведёт
дальше. Крестик на первом шаге закрывает флоу. «Продолжить» на втором
шаге пока без действия — следующий экран будет отдельной задачей.

Ограничения: крестик, стрелка назад и шит — нативные, не рисуй их
по макету картинками. Экран счёта не переделывать.

Готово, когда: флоу открывается шитом, галочка переносится по тапу,
крестик закрывает, «Продолжить» пушит второй шаг.
```

## Карусель дизайнов

Финальный шаг открывает карусель дизайнов: свайп с пружиной, чипы коллекций, кнопка меняется вместе с картой. Три фрейма макета — это не три экрана, а три состояния одной карусели.

![](../assets/practice/case-2-step-3.png)

```
Контекст: финальный шаг флоу «Выпуск новой карты».

Задача: шаг выбора дизайна. Три фрейма макета — это состояния одной
карусели:
https://www.figma.com/design/2UQNBYDCGL5UrNXp1JbTJX/Воркшопы?node-id=23-39891
https://www.figma.com/design/2UQNBYDCGL5UrNXp1JbTJX/Воркшопы?node-id=36-2340
https://www.figma.com/design/2UQNBYDCGL5UrNXp1JbTJX/Воркшопы?node-id=36-2456
Картинки дизайнов уже в проекте: CardDogBlack, CardDuckBlack, CardCatBlack.

Поведение: карты листаются свайпом с пружиной, активная по центру,
соседние выглядывают по краям. Сверху лента чипов коллекций, активный
подсвечен. Под картой название и описание, ниже пейджер. Кнопка внизу
меняется вместе с картой: «Выпустить бесплатно», у Котятского —
«Выпустить за 799 ₽». Шаг открывается, если на прошлых шагах выбрано
«Для себя» и виртуальная или пластиковая карта. Тап по кнопке закрывает
флоу, а выпущенная карта появляется в ленте на экране счёта.

Ограничения: обводка карт — токен границы white 10%, тот же, что у карт
на экране счёта: активная 2 pt, соседние 1 pt. Активный чип центрируй
средствами ScrollView, не пересчитывай позиции через измерение геометрии
вью — это даёт рекурсию раскладки, и приложение зависает намертво.

Готово, когда: шаг открывается мгновенно и не подвисает; свайп листает
с пружиной; чип, пейджер и текст кнопки меняются вместе с картой; после
выпуска карта видна в ленте на экране счёта.
```
