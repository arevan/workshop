Полноэкранная физическая песочница: эмодзи сыплются сверху, копятся кучей внизу, пересыпаются от наклона телефона и лопаются от тапа. Пять промтов — ровно в том виде, в котором они дают рабочий результат без правок руками.

> Шаги не объединяй: запускай приложение после каждого. Промты копируй целиком — формулировки выглядят избыточно подробными, но каждая строка в них закрывает конкретную поломку.

![](../assets/practice/case-1-phone.jpg)

## База: физика, эмодзи, кнопки

Первый запуск даёт работающую песочницу целиком: куча копится, кнопки управляют. Всё остальное — надстройки над этим.

```
Собери в этом проекте полноэкранную физическую песочницу на SwiftUI + SpriteKit
через SpriteView, вместо текущего содержимого ContentView.

Сцена:
— Фон чёрный, во весь экран, без отступов и без учёта safe area.
— Тела — эмодзи 🤡. Видимый диаметр лица случайный от 28 до 72 точек.
  Именно непрерывный разброс, а не две-три фиксированные ступени.
— У каждого круглое физическое тело: они сталкиваются, вращаются,
  скатываются и накапливаются внизу, как горсть монет.
— Эмодзи отрисуй в текстуру один раз и переиспользуй для всех тел. Размер
  шрифта и поля не подбирай на глаз: после отрисовки найди по альфа-каналу
  прямоугольник непрозрачных пикселей — это видимая часть символа. Спрайт
  масштабируй так, чтобы видимая часть имела нужный диаметр, а физический круг
  задавай по ней же, а не по размеру холста или спрайта.
— Проверь результат глазами: тела в куче должны лежать вплотную, соприкасаясь.
  Чёрные просветы между ними означают, что круг больше видимой части.
— Стенки замкнутые, со всех четырёх сторон, включая верх. Новые тела создавай
  внутри сцены, чуть ниже верхнего края, а не над ней.
— Сцене задай конкретный ненулевой стартовый размер и scaleMode = .resizeFill.
— Включи телам usesPreciseCollisionDetection, а в update вправляй обратно
  внутрь сцены тех, кто всё же оказался за её границами. Именно вправляй
  на месте, а не возвращай наверх.
— Максимум 90 тел. На пределе лопается случайное тело и сразу создаётся новое.

Лопание вынеси отдельным методом, он понадобится ещё раз:
тело раздувается до 1.3 и гаснет за 0.14 сек, из центра разлетаются восемь
светлых частиц по 12 точек — на 26–44 точки, с уменьшением и угасанием за 0.22 сек.

Кнопки:
— Сверху слева две капсульные кнопки: «Reset» убирает всех, «Spawn» сыплет новых.
— Оформи материалом Liquid Glass: .glassEffect(.clear, in: .capsule),
  все внутри GlassEffectContainer.
— Шрифт 17 semibold, отступы 18 по горизонтали и 11 по вертикали.
— Пока палец удерживает Spawn, поток не прекращается.

Ориентация только портретная.
Больше ничего не добавляй: ни настроек, ни меню, ни других экранов, ни звука.
```

## Гравитация по наклону

Момент «вау», и увидеть его можно только с телефоном в руках: в симуляторе акселерометра нет.

```
Пусть гравитация следует реальному наклону телефона: наклоняю устройство —
тела пересыпаются в ту сторону, которая физически ниже. Интерфейс при этом
не поворачивается.

Если акселерометр недоступен, гравитация должна остаться направленной вниз
по экрану, чтобы приложение работало как раньше.
```

## Два жеста: тап и протяжка

Тап лопает, ведение расталкивает. Это разные вещи, и в промте они разведены явно.

```
Добавь два разных жеста по экрану.

Тап: тело под пальцем лопается — тем же методом, что уже используется при
достижении предела, не пиши второй. Попадание считай по видимому лицу, а не
по прямоугольнику спрайта. Если под пальцем несколько наложившихся,
лопается верхний.

Ведение пальцем не отрывая: тела не лопаются, а расталкиваются — вокруг пальца
открывается свободное место, и масса смыкается обратно, когда палец убран.
Сделай это невидимым круглым физическим телом радиусом около 45 точек,
которое следует за касанием.
```

## Тактильный отклик

Полировка. Делается последней — когда всё остальное уже работает.

```
Добавь тактильный отклик на два события: тело лопнуло — короткий отчётливый
щелчок; тело ударилось о стенку — заметно более слабый.

Удары о стенку идут пачками, поэтому ограничь их частоту: не чаще одного раза
в несколько сотых секунды и только при достаточно сильном ударе. Иначе при
потоке из Spawn телефон превратится в сплошную дрожь.
```

## Смена эмодзи

Самый короткий промт из пяти: нужный экран писать не нужно, он уже есть в системе.

```
Добавь третью капсульную кнопку «Settings» в том же стиле, что Reset и Spawn.
По нажатию она открывает системную клавиатуру эмодзи — ту самую панель
с поиском сверху, сеткой и категориями снизу. Не воспроизводи её своими
средствами и не собирай свой список эмодзи.

Делается скрытым текстовым полем: textInputMode принудительно переключён
на режим emoji, keyboardAppearance — тёмный.

Выбранный символ становится новым телом песочницы. Уже заспавненные при этом
убираются, куча набирается заново: подменять текстуру на месте нельзя,
получается мгновенная подстановка одного символа другим.
```
